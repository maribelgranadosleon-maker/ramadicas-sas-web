Privacidad y uso de datos

Este sitio es una demostración académica para el proyecto formativo SENA. Antes de utilizarlo con información real, solicita autorización a la empresa y define quién podrá consultar, conservar y eliminar los datos.

  • Recolecta únicamente información necesaria y autorizada.
  • Explica a los participantes para qué se usarán sus respuestas.
  • Evita almacenar datos sensibles o identificaciones innecesarias.
  • Protege el acceso al servidor y realiza copias de seguridad de forma segura.

La base de datos de esta demostración se guarda localmente en el archivo ramadicas.db.
